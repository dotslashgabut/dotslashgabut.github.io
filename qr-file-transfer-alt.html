QR File Transfer

Encode any file into a sequence of animated QR codes and record it as a video. Decode that video back into the original file — all in the browser, no server involved.

Encode settings

QR capacity per chunk depends on error correction: L≈2900, M≈2300, Q≈1600, H≈1250 characters (already includes a bit of header overhead). More loops = the video is more resilient to frames that fail to decode later.
