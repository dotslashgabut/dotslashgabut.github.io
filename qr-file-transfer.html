QR File Transfer

Encode file apapun jadi rangkaian QR-code yang dianimasikan lalu direkam ke video. Decode video itu balik jadi file aslinya — semuanya di browser, tanpa server.

Sumber file

File akan dibaca sebagai base64, dipecah jadi beberapa bagian, tiap bagian jadi 1 frame QR.

Klik untuk pilih file, atau drag & drop di sini

Pengaturan encode

Kapasitas QR per chunk tergantung error correction: L≈2900, M≈2300, Q≈1600, H≈1250 karakter (sudah termasuk sedikit overhead header). Loop lebih banyak = video lebih tahan terhadap frame yang gagal ke-decode saat proses decode nanti.

Pengaturan decode

Sample rate sebaiknya ≥ fps yang dipakai saat encode, supaya tidak ada frame QR yang terlewat. Kalau ada chunk yang hilang setelah proses selesai, naikkan angka ini lalu coba lagi.
